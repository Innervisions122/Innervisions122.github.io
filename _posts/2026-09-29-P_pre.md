## 一、logisim

我在搭建电路时一直会遇见一个问题，就是不会实现 if 电路。以下是我问 chatgpt 的回答：

| 程序思维 | 硬件思维 |
|---|---|
| `if` | MUX / 选择电路 |
| `a == b` | 比较器 / XNOR 等 |
| `a > b` | 比较器 |
| `else` | 另一条数据路径 |
| `for` | 并行展开的重复硬件 / 组合逻辑 |

……

实在对我没起多大作用，又看了群友们的做法，

![太强了](https://github.com/Innervisions122/Innervisions122.github.io/blob/main/assets/images/061b26aeecc123d567f4a24293c6bef2.png)

真是难以实现，但看了 hint 的内容，结合理论课上的一些例子，其实可以**把得到的信号全部分成一位，输出的信号也分成一位，通过逻辑运算即可完成 if 判断**。而 logisim 中又自带真值表生成电路图的功能，在此时以及以后搭状态机时会有很大作用。

同时， hint 的内容让我第一次意识到 tunnel 的威力，既可以很好地理清思路，又不至于在做复杂电路时连出一堆可怕丑陋的玩意儿来，有需要则使用。

再回到题目本身，它特意给了 0 到 15 这特殊的 16 个首尾相接的站台，暗示我们可以不用特意判断什么时候 clockwise 什么时候 counterclockwise ，直接相减，便已能完成

| `顺时针距离` ｜ (B - A) mod 16 |
| `逆时针距离` ｜ (A - B) mod 16 |

的功能，最后只要注意判断两种 cw == ccw 的情况就可以了。
